# Cyber Security & Linux Quiz CLI 🚀

An interactive Bash script-based command-line quiz game focused on Linux commands, networking fundamentals, and cybersecurity basics. Designed for tech learners and enthusiasts to test their terminal skills!

## Features 🛠️
* **30 Interactive Questions:** Covers essential Linux commands, ports, networking protocols, and security tools.
* **Score Tracking:** Keeps count of your correct answers and displays the final score.
* **Easy to Run:** Lightweight Bash script that runs directly in any standard Linux terminal or Termux.

## Prerequisites 📋
* A Unix-like shell environment (Bash)
* Standard Linux utilities
